# Crop Data Analysis Project

## Data Dictionary

The dataset contains the following features:

### Environmental Parameters

- **Temperature (°C)**: Optimal temperature for each crop.
- **Humidity (%)**: Required humidity level for optimal growth.
- **pH**: Soil pH level suitable for each crop type.
- **Water Level (mm)**: Required water amount for cultivation.

### Target Variable

- **Crop**: The crop type, encoded as follows:

| Crop         | Encoding |
| ------------ | -------- |
| Bell Pepper  | 0        |
| Bitter Gourd | 1        |
| Carrot       | 2        |
| Corn         | 3        |
| Cucumber     | 4        |
| Eggplant     | 5        |
| Green Chili  | 6        |
| Okra         | 7        |
| Potato       | 8        |
| Rice         | 9        |
| Tomato       | 10       |

## Project Overview

This project analyzes environmental factors affecting crop growth to predict optimal growing conditions for various crop types.
